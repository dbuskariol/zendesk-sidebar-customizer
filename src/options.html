      Ticket list — General v0.9

      Customize the Zendesk ticket-list table (the page at /agent/filters/… and any other ticket queue). All of this works on any view — there's no hardcoded column, status, or layout assumption. Columns and statuses are discovered live per tenant; non-English values stay unclassified until you map them below.

      Ticket list — Density

      Spacing tokens for the ticket-list table. Active when Compact mode is on above. The label next to each slider shows Zendesk's intrinsic value; drag to override.

      Ticket list — Columns

      Columns discovered on this tenant. Uncheck to hide a column from every ticket list. Custom-field columns (tenant-specific) are keyed by their Zendesk ID so they stay scoped to this tenant — they will not leak to other tenants you sync.

        Ticket list — Colors

        Row coloring rules. Status and priority values are auto-discovered — assign each to a semantic bucket (open / pending / solved / etc) to get a color. Non-English values stay unclassified until you map them. SLA buckets are matched against text patterns you can edit.

        SLA patterns

        Regex patterns matched against each SLA cell's text. Bucket determines color. Defaults match the English Zendesk strings; add patterns for your locale.

        Bucket colors

        Ticket list — Auto-refresh

        Periodically click Zendesk's own refresh button. Pauses when the tab is in the background and when you have any rows selected (so bulk-action workflow isn't interrupted).

        Ticket list — Theme

        Color overrides for the ticket-list table. Active when Theme overrides is on at the top.
